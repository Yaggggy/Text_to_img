# Text_to_img

**Text_to_img** is a web-based application that generates images from text input. It provides a simple and efficient way to visualize concepts and ideas.

## Features
- Convert text prompts into images instantly.
- User-friendly interface with a clean design.
- Responsive and works across devices.

## Tech Stack
HTML, CSS, JavaScript

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/Yaggggy/Text_to_img.git
   cd Text_to_img
   ```
3. Run the application:
   ```run the index.html file 
   ```
